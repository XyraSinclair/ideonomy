After this first run through the Set of Scaling Dyads has been
completed, and Pole A has been scaled as a result, a new Scaling Pole, say

Set is executed on this basis.

All of this is repeated for however many Poles (or visual textures) one
wishes to map, but always for the same General Referent texture, B.

However, after this run-of-runs, or meta-run, is concluded, one does
indeed replace (in the new meta-run that is to be executed next) the old
invariant General Referent texture B with a new invariant General
Referent texture, H.

This higher-level substitution is repeated, however many times one
wishes, so that one executes a run-of-runs-of-runs (or meta-meta-run).
